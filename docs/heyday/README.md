# Heyday brief pack

Everything planned for the Heyday websites, as of 13 September 2026. It was put together by Jem, with Claude.

## How to use it

1. Unzip it into `docs/heyday/` at the top of the jobbie repo.
2. Paste the build prompt into Claude Code. The prompt is `HEYDAY-JOBBIE-FULL-SITE-PROMPT.md`, and it's also on Jem's build page.

Where a document says `~/Projects/heyday-upandup-brief/`, it means this folder. The claude.ai links in the documents are Jem's private pages. Everything they show is in this pack.
